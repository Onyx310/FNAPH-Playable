This repository houses a 3D game I designed in Unity after being inspired by an idea presented by my friends.

You can play the game here: https://onyx310.github.io/FNAPH-Playable/

This game is a 'defend the office' style game based on the hit game series Five Nights At Freddy's. I was only able to make the base framework for the game and add one entity. However, because this is set up it is relatively easy for me to add more entities in the future. I made all of the 3D assets in the game including the animation for the one and only entity. The entity's logic works exactly like how the logic in the original Five Nights At Freddy's game works: there is an 'ai level' and every 2 seconds the entity will pick a random number 1-20 and if this number is below it's 'ai level' then it will progress towards you. 

I wrote all of the scripts in C#: https://github.com/Onyx310/FNAPH-Scripts
